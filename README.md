== Description ==

WooCommerce Product Attribute Dynamic Tags for Elementor helps WooCommerce store owners dynamically display product attributes inside Elementor widgets without custom coding or shortcodes.

Instead of manually inserting product data, this plugin adds a dedicated Elementor Dynamic Tag for WooCommerce product attributes so you can create modern and fully dynamic product templates.

It works perfectly with Elementor Pro Product Loop Grid, Loop Builder, custom product cards, archive templates, and WooCommerce product layouts.

Perfect for:

* Tire & Automotive Stores
* Fashion & Clothing Stores
* Electronics Stores
* Furniture Stores
* Product Catalog Websites
* Custom WooCommerce Shops

You can dynamically display product information such as:

* Product Size
* Width
* Height
* Diameter
* Season
* Color
* Brand
* Fuel Class
* Noise Level
* Shipping Time
* Material
* Storage
* RAM
* Any WooCommerce Attribute

The plugin behaves similarly to Elementor Product Terms and allows dynamic attribute selection directly inside Elementor.

== Installation ==

1. Upload the plugin ZIP file to WordPress.
2. Activate the plugin.
3. Open Elementor editor.
4. Select any widget such as Heading or Button.
5. Click Dynamic Tags.
6. Choose Product Attribute.
7. Select the WooCommerce attribute from dropdown.
8. Save and publish.

== Frequently Asked Questions ==

= Does this plugin work with Elementor Pro? =

Yes. Elementor Pro is recommended for Product Loop Grid, Loop Builder, and advanced WooCommerce layouts.

= Does this support WooCommerce global attributes? =

Yes.

Examples:

pa_color

pa_size

pa_brand

pa_material

= Does this support custom product attributes? =

Yes. Both custom product attributes and WooCommerce global attributes are supported.

= Can I use it inside Elementor Buttons? =

Yes. The plugin uses text-safe output to prevent broken layouts inside buttons.

= Does it work with Product Loop Grid? =

Yes. It is optimized for Elementor Product Loop Grid and custom WooCommerce layouts.

= Does it require coding knowledge? =

No. Everything works visually inside Elementor Dynamic Tags.
